# Changelog

## 2.2.0 - 2026-09-26

### Public release preparation

- Prepared the theme for a standalone public GitHub repository.
- Added BetterDiscord `@website` and `@source` metadata.

- City of Glass-inspired light architectural surfaces.
- Runner-red server / DM navigation composition.
- Dark structural server rail.
- Original embedded rooftop / wayfinding background motif.
- Styled mentions, reactions, unread dividers, message composer, menus, dialogs, and focus states.
- Reduced-motion handling.
